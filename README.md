
# Hi there!
I am an Application Engineer working at the intersection of simulation, testing, and real-world validation. I build tools and automation pipelines that connect measured data to simulation environments, and extend simulation models at the code level when off-the-shelf solutions fall short.<br>My work spans vehicle dynamics, multibody simulation, HIL/SIL testing, and ADAS applications. I write in C/C++, Python, and MATLAB, and I'm comfortable working across the full chain from model development and parameterisation to test execution and results correlation.
<br>M.Sc. in International Automotive Engineering. Based in Ingolstadt, Germany. Open to opportunities across automotive, robotics, and adjacent industries.
